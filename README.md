# 🌙 Moon Pong Game

A classic Pong game built with HTML5, CSS3, and JavaScript.  Control the moon paddle and compete against an AI opponent!

## Features

✨ **Moon Paddle Character**  
🎮 **Mouse & Keyboard Controls**  
🤖 **AI Opponent**  
📊 **Dynamic Level System**  
📱 **Progressive Web App (PWA)**  
🔌 **Offline Support**  
📲 **Mobile & Desktop Compatible**  

## How to Play

- **Mouse**: Move paddle smoothly with your mouse
- **↑ Arrow Key**: Move paddle up
- **↓ Arrow Key**: Move paddle down
- Score points when the ball passes your opponent
- Game difficulty increases with each level

## Installation

### Play Online
Visit:  `https://fmburu744-art.github.io/pong-moon-game/`

### Install as App
1. Open the game in Chrome, Edge, or a mobile browser
2. Look for "Install" button in the address bar or menu
3. Click "Install Moon Pong"
4. Play offline anytime!
